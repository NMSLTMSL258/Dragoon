# Dragoon

把现代战场搬进《英雄连2》，再看看谁先把地图拆了。

步兵换了家伙，装甲换了年代，指挥官也带着一堆新玩具进场。Dragoon 这次开门公测，放出 RU / CH / US / EU / MEC 的当前完整内容；步枪、步战车、主战坦克和火力支援，都来这张老战场上重新认识一下。

版本还在长，平衡和细节也会继续磨。欢迎来玩，也欢迎来抓虫；遇到问题，带上阵营、单位或技能名、当时在做什么，有截图就更好了。吐槽可以猛一点，线索记得留一点。

下载与安装
1. 在 GitHub 发布页下载 .001、.002 两段，以及 Merge_Dragoon.cmd，放进同一文件夹。
2. 双击 Merge_Dragoon.cmd，等待显示 OK。工具使用 Windows 自带 PowerShell 合并并校验，无需管理员权限。
3. 解压生成的 Dragoon_Beta_20261116_Full.zip。若拿到别人转发的完整 ZIP，直接解压即可。
4. 正常退出 CoH2，将整包中的 mods 文件夹合并到“文档/My Games/Company of Heroes 2”，或此前搬迁后的实际目录。
5. 调校选择 Dragoon - Release；胜利条件选择 Dragoon Release Commanders - Victory Points 或 Annihilation。

整包只有三个 SGA：
mods/tuning/Dragoon_Release.sga
mods/assets/Dragoon_Release_Assets.sga
mods/gamemode/Dragoon_Release_Commanders.sga

开发版与独立发布版可以并存。公测下载无需仓库邀请。
GitHub 自动生成的 Source code 压缩包不是完整 MOD。
